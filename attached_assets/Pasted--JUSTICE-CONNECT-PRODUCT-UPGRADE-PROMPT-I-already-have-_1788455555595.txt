# JUSTICE CONNECT — PRODUCT UPGRADE PROMPT

I already have an existing Justice Connect full-stack application.

**DO NOT rebuild the existing project from scratch.**
**DO NOT repeat or recreate features that already exist.**
First inspect the current codebase, database schema, API routes, dashboards, and existing functionality.

The goal now is to upgrade the existing project from a prototype into a more complete, realistic product.

---

# 1. IMPORTANT CHANGE — REMOVE COURT CASE NUMBER CONCEPT

The existing implementation currently uses sample court-style case numbers such as:

`CIV-2026-00124`

REMOVE this concept from the product.

Justice Connect must NOT ask citizens to enter or provide an official court case number.

Justice Connect will have its own internal case identification system.

### Justice Connect Case Number

When a citizen submits a new case/request, the backend automatically generates a unique number such as:

`JC-2026-000184`

This number belongs ONLY to Justice Connect.

It is a:

**Justice Connect Case Number / Tracking Number**

It is NOT an official court case number.

Do not mention or require court case numbers anywhere in the new case workflow.
